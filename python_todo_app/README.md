# Python CLI To-Do App

A command-line To-Do application built with Python.

## Features

- Add tasks
- View tasks
- Complete tasks
- Delete tasks
- Save tasks
- Load tasks

## Technologies

- Python
- JSON
- Git

## How to Run

Clone the repository:

git clone 

Create virtual environment:

python -m venv venv

Activate environment.

Run:

python app.py
